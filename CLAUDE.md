# screenshot-swipe-privacy

Privacy-policy hosting for **Screenshot Swipe: Smart Notes** (App Store id
6757885971) at `https://mjrode.github.io/screenshot-swipe-privacy/`.

**The real marketing site + blog is `../promo-page` → https://screenshotswipe.com.**
This repo exists only because the App Store listing's privacy-policy URL may
point here. The root `index.html` redirects to screenshotswipe.com; the policy
lives at `/privacy/` (noindexed — the canonical copy is
screenshotswipe.com/privacy/).

GitHub Pages serves the `main` branch root — push = deploy.

Do not add content here. Blog posts, skills, and SEO tooling live in
`../promo-page`.
